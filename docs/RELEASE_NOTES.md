# PAMWeave 0.1.0

Based on the competition submission at source repository commit `7a953b3`. This release adds public-facing documentation, an MIT license for original code, contribution guidance and third-party notices. Analysis source files, registered inputs, reference scores and candidate CSV files are unchanged from the checked submission package.

The 22-system reference results and 21-system redistributable reproduction remain distinct. Clean-machine installation, user trials, GPU execution and wet-lab validation are not claimed.
