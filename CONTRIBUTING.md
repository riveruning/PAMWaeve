# Contributing

Open an issue with the input format, command, environment and a minimal reproducible example. Do not upload credentials, private sequences, unlicensed data or model weights.

Keep prediction, biological evidence and experimental validation distinct. Changes to scoring, cohort eligibility or abstention require a documented rationale and meaningful regression coverage. Run `PYTHONPATH=src python scripts/run_tests.py` before submitting changes.

For data additions, include source, license, file checksum, assay context and training-exposure assessment. Contributions of original code are submitted under the repository MIT license; third-party material retains its source terms.
